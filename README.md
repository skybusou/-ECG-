# 『万響札』-ECG-
共通の山札がプレイヤーの選択で動的に変異する、新時代の2人用拡張型カードゲーム（ECG）『万響札』の公式リポジトリ。 基本セット（無料）の堅牢なルールOSの上に【拡張属性】 【属性変更】を各1つずつ持ち込み、最大4パックが戦場で複雑に交差する緻密なゲームデザイン。総枚数200枚未満の有限なプールでありながら、手札・山札・捨札を巻き込む極限の脳内演算と、体験の変革をもたらします。   本リポジトリでは、ver.7の最新仕様から各種拡張パック（相棒/爆弾/道具/腐蝕/溜撃）の統治ルール、エッジケースのバグフィックスまでを完全に構造化して管理します。

『万響札』[ver.7]
・『万響札(まんきょうふだ)』のジャンルは『拡張型カードゲーム(ECG)』である。

◯セットアップ(2人用)
①基本カード10枚の内、参加者の場に1枚ずつ《防御》を表向きで場に出す。
②基本カードの残り8枚を裏向きにシャッフルして、相手に見えない様に参加者に1枚ずつ渡す。(=ゲーム開始時の手札)
③場に《防御》が2枚、互いに手札が1枚ずつ、残りのカードは6枚となる。
(※初心者の場合は、手札を全て公開すると良い)
④残りの6枚を山札として、裏向きのまま場に置く。
⑤人数分、初期HP13のカウンターを用意する。
⑥最初に出番を始める人を決める。

◯基本カード：属性が１つ(各2枚、計10枚)

《攻撃》：①(※自分の)場に(※このカードを)出す。②(※次の自分の出番になったら)6dmg(※ダメージを相手全員に与える)。③自壊(※処理が終わったらこのカード破壊)。

《防御》：①場に(※出して)残す。②+1シールド(※使うと先にこのカード破壊し、dmgを無効[0dmg]にする。戦術によってはあえて使わなくてもよい、自分のカードによるdmgにも使える)。

《追加》：①場に出す。②(山札から)2ドロー。③2枚(手札を)捨札に置く。④自壊。 

《対策》：①場に残す。②(次の自分の出番から)出番中、+1破壊。(※このカードで破壊を行うと、このカード破壊する)

《変化》：①自分の手札1枚を追加でコストにして捨てる(=コスト1枚)、場に出す。
(※手札の残りがなければ、コストは無い)
②その後(=①処理後)、《攻撃×攻撃》《防御×防御》《追加×追加》《対策×対策》から1枚公開して手札に。③全て無ければ、捨札から(※超越カード以外で)1枚公開して手札に。④ (※捨札すら1枚も)無ければ、1ドロー。⑤自壊。

《防御×追加》：①場に残す。②このカード破壊された時、-4HP(※あなたのHPが0以下になると、あなたはゲームに敗北する)。③(※このカードが場にある間)+4HP。

(※《変化》系のカードで手札は増やせる)

(※相手の場に1枚も無ければ効果無しになる)

③無ければ、1ドロー。④自壊。

③無ければ、1ドロー。④自壊。

◯コンセプト
遊ぶ度に、参加者の選択が、共通の山札に増えるカードを決める！

◯ルール説明：
・さまざまな属性の付いたカードで戦う。
・毎出番、引いたカードと手札に持ってる2枚から1枚を選び、相手の体力(=HP)を減らして勝つ。
・特色：共通で使う山札は、プレイヤー全員のカード選択に合わせて、多彩にカードが増える。
・属性が3つの超越カード以外の、基本カード、上位カードの性能に上位互換のカードはない。
・このゲームのdmg表記は、次の自分の出番に処理する。
・待機中のカードとは、山札、手札、場に存在せず、今後、山札に加えられる可能性があるカード群の事である。

　出番共通：
①既に場にあるカード(※《攻撃》系など)の効果を発動する(＝開始処理)。【開始フェイズ】
② 共有山札から1枚引く(＝1ドロー)。【ドローフェイズ】
③カードを必ず1枚選び、処理する(＝1行動)。【行動フェイズ】
④次の相手の出番に変わる(＝出番終了)。【終了フェイズ】

　捨札：
①捨札はカードに書かれた順番に重ねる。

手札：
①手札にカードがあれば、出番に出さなければならない。

遊びやすくする為：
①待機中のカードと捨札は、基本カード、上位カード、超級カードで山を分けるといい。

山札：
①ドローする時、山札がなければ、新たに作る。
②超級カードの属性と同じ組み合わせの、基本カードと上位カードがあれば、対応する超級カード1枚と合わせて3枚セットを作る。
③その後、待機中の上位カード属性と同じ組み合わせの、基本カード2枚があれば、対応する上位カード1枚と合わせて3枚セットを作る。
④組み合わせの確認は、一番上にあるカードから行い、全ての組み合わせを確認する。
⑤完成した3枚セットを全て混ぜて、山札にする。
⑥基本カードが3枚以上あり、組み合わせ可能な上位カードを、山札にこれ以上加えられない時は、基本カード3枚に対応する超越カード1枚と合わせて4枚セットを作る。
⑦捨札にある超越カード及び、組み合わせが可能な上位カード、超越カードが既に山札に加えられていて、組み合わせがこれ以上作れない場合は、捨札のままになる。


◯よくある間違い
①基本カード合計10枚により、必然的に序盤に引けるカードは予想が付くが、意図的設計である。相手や自分が一方的に序盤からゲームを支配する可能性を下げてる。

② 山札を作り直す際、超越カードや上位カードに触れる機会を増やして欲しいので、捨札にある端数1枚の基本カードや、場合によっては、待機中の超越カードと上位カードに対する組み合わせが存在しない捨札の基本カードは何枚あっても捨札に置かれたままである。

③そもそも『万響札』は拡張パックと合わせて楽しむ事が前提である。第一世代では10種類の拡張パックを随時製作中である。詳しくは@yoruno_18で《爆弾》属性を検索。

④相手の《攻撃》からの6dmgは、相手の次の出番開始の【開始フェイズ】に発生する。《攻撃》を出した出番中や、相手の出番中には処理しない。

⑤毎出番、行動必須なのは『万響札』での公平性の核心である。

⑥ゲーム開始してから、一度も開始6枚の山札が作り直されてなければ《変化》の処理以外で、山札から上位カードと超越カードのどちらも引けない。仮に【一度も山札が作り直されてないのに】引いたなら何かの準備を間違えてる。

⑦《変化》などの【①自分の手札1枚を追加でコストにして捨てる(=コスト1枚)、場に出す】では、必ず行動処理を行なってる《変化》をコストに使えない。《変化》の場合、《変化》を行動処理したいのならば、先に【行動処理させたい《変化》】以外の手札(手札が無ければ無くてもいい)1枚を先に捨てる必要がある。これがコスト1枚の意味である。その後に《変化》を場に出して②以降の処理を行う。

⑧《変化》で手に入るカードは待機中の《攻撃×攻撃》《防御×防御》《追加×追加》《対策×対策》のみであり、《変化×変化》は手に入らない。《変化》で上位入手の利点はカードパワーではない。望む属性のカードを手に入れやすい事である。

⑨上位や超越カードなどの処理のコンボによって、自分の手札が0枚になる事はある。

⑩基本カードと上位カードに強弱なし。上位はリスク高（妨害即不利)などの場合がある。それでも選択肢の広さは上位カードの方が高い。
